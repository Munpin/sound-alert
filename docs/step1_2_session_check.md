# 1단계-2: 녹음 회차 확인 스크립트 (2026-11-26)

## 이 문서를 받은 Claude Code에게

- 설계서는 `docs/design_v2.md`, 녹음 설정은 `docs/recording_setup.md`다.
- 오늘 저녁 나는 녹음 페이지로 초인종·노크 회차를 녹음한다. 회차를 하나 녹음할 때마다 이 스크립트로 바로 확인하려고 한다.
- 쉬운 한국어로 설명하고, 큰 결정은 먼저 묻는다. 데이터 파일은 저장소에 올리지 않는다.

## 녹음 방식 (스크립트가 알아야 할 것)

- 한 파일 = 한 회차. 파일 이름은 `클래스_MMDD_sXX_장소_phone.wav`
- 파일 앞부분 약 30초는 **벨이나 노크가 없는 배경**이다.
- 그 뒤 초인종은 10초 간격으로 10번, 노크는 5초 간격으로 10번(한 번에 2~3번 두드림)
- 배경만 녹음한 파일은 클래스가 `other`다.

## 만들 것: `train/check_session.py`

실행: `python train/check_session.py data/raw/doorbell_1126_s01_desk_phone.wav --expect 10`

확인하고 화면에 출력할 것:
1. **파일 이름**이 규칙에 맞는지
2. **형식**: 16000 Hz, 모노, 16비트
3. **클리핑**: 잘린 샘플 수, 최댓값(dBFS)
4. **소리 구간 찾기**: 앞부분 배경으로 평소 음량을 재고, 그보다 확실히 커진 구간을 소리로 찾는다. 찾은 개수와 각 구간의 시작·끝 시각을 출력한다. `--expect`와 개수가 다르면 눈에 띄게 경고한다.
   - 초인종: 한 번 누르면 약 4초 동안 울린다. 가까운 구간은 하나로 묶는다.
   - 노크: 2~3번 두드림이 한 묶음이다. 1초 안의 두드림은 하나로 묶는다.
5. **그림**: 스펙트로그램에 찾은 구간을 표시해 `data/checks/<파일이름>.png`로 저장한다.
6. **구간 목록 저장**: `data/segments/<파일이름>.csv` (시작, 끝, 라벨). 구간 사이와 앞부분 배경은 `other`로 적는다(설계서 4절: 구간 사이는 같은 회차의 '그 외').
7. **meta.csv**: 그 파일의 줄이 `data/meta.csv`에 있는지 확인하고, 없으면 알려 준다.

배경만 녹음한 `other` 파일은 4번에서 구간을 찾지 않고 길이와 평균 음량만 출력한다.
