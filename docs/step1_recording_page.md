## 목표

휴대폰(갤럭시 S24 Ultra, 안드로이드 16, 크롬 158) 크롬에서 열어, 실제 알림 앱과 **같은 마이크 경로**로 소리를 녹음하고 16 kHz wav로 저장하는 페이지.

이 페이지의 마이크 입력 부분은 나중에 알림 앱에서 그대로 다시 쓴다. 그래서 학습 데이터와 실제 사용 때 들어오는 소리가 같아진다.

## 1. 프로젝트 구조

```
sound-alert/
├─ web/              # 휴대폰 웹앱 (GitHub Pages로 배포)
│  ├─ index.html
│  ├─ audio-input.js # 마이크 → 16 kHz 모노 신호 (알림 앱에서도 재사용)
│  └─ recorder.js    # 녹음, wav 저장, 파일 이름
├─ train/            # 학습 코드 (나중에)
├─ data/             # 녹음과 공개 데이터 (저장소에 올리지 않음)
│  ├─ raw/
│  └─ meta.csv
├─ docs/
│  ├─ design_v2.md
│  └─ recording_setup.md
└─ .gitignore        # data/, *.wav 등 데이터 파일 제외
```

**데이터 파일(wav 등)은 절대 저장소에 올리지 않는다.** 공개 데이터 이용 조건 때문이다.

## 2. 녹음 페이지 요구사항

**마이크**
- 시작 버튼을 눌러야 마이크를 켠다(크롬은 사용자가 한 번 눌러야 마이크를 허용한다).
- `getUserMedia`에서 `echoCancellation`, `noiseSuppression`, `autoGainControl`을 모두 `false`, 채널 1로 요청한다.
- 실제 적용된 값(`track.getSettings()`)을 화면에 보여 준다. 셋이 모두 꺼졌는지 눈으로 확인하기 위해서다.

**16 kHz 변환**
- 브라우저에서 16 kHz 모노로 바꾼다. `AudioContext({ sampleRate: 16000 })`이 되면 그걸 쓰고, 안 되면 원래 샘플레이트로 받아 JavaScript로 변환한다. 어느 쪽을 썼는지 화면에 표시한다.
- 소리 받기는 `AudioWorklet`으로 한다(예전 방식인 `ScriptProcessorNode`는 쓰지 않는다).
- 이 부분은 `audio-input.js`로 분리해, 나중에 알림 앱이 똑같이 쓸 수 있게 한다.
- **저장하는 wav는 모델이 받을 16 kHz 신호 그대로여야 한다.** 저장할 때 다시 변환하지 않는다.

**녹음과 저장**
- 녹음 시작/정지 버튼, 경과 시간, 음량 막대, 소리가 너무 커서 잘릴 때(클리핑) 경고
- 녹음하는 동안 Wake Lock으로 화면을 켜 둔다.
- 저장 형식: wav, 16 kHz, 모노, 16비트 PCM. 휴대폰에 다운로드된다.

**파일 이름 규칙** (설계서 4절)
- `클래스_날짜_회차_장소_기기.wav` (예: `doorbell_1126_s01_desk_phone.wav`)
- 입력칸
  - 클래스: 선택 목록(doorbell, knock, baby_cry, siren, horn, other)
  - 날짜: 자동(MMDD)
  - 회차: s01, s02 … (직접 입력, 기본값은 이전 값 + 1)
  - 장소: 짧은 영문(desk, bed, bath, entrance, kitchen, outside)
  - 기기: phone 고정
- 배경 소리와 휴대폰 상태(책상 위, 손, 이불 위)도 입력받는다. 이건 파일 이름에 넣지 않고, 저장할 때 `meta.csv`에 붙여 넣을 한 줄을 화면에 보여 주고 복사 버튼을 둔다.

## 3. 메타데이터 표

`data/meta.csv` 머리글:

```
file,class,source,group_id,split,place,background,phone_state,device,date,license,note
```

- `group_id`는 회차 ID다(예: `phone_1126_s01`). 분할 단위가 된다.
- `split`은 나중에 정한다. 비워 둔다.

## 4. 배포

- GitHub 저장소를 만들고 `web/` 폴더만 GitHub Pages로 배포한다.
- 휴대폰 크롬에서 https 주소로 열리는지 확인한다(https여야 마이크가 켜진다).

## 5. 확인 (모두 통과해야 완료)

1. 휴대폰에서 페이지가 열리고 마이크 허용 창이 뜬다.
2. 화면에 표시된 `getSettings()` 값에서 세 가지 처리가 모두 `false`다. 하나라도 `true`면 나에게 알린다(설계서 8절 위험).
3. 10초 확인 녹음(조용히 → 박수 → 벨 또는 휴대폰 알림음)을 저장해 PC로 옮긴 뒤 Python으로 확인한다.
   - 샘플레이트 16000, 채널 1, 16비트
   - 스펙트로그램 그림: 4 kHz 위쪽 높은 소리까지 보이는지
   - 최댓값이 잘리지 않았는지(클리핑 없음)
4. `docs/recording_setup.md`를 만든다: 휴대폰 기종, 안드로이드·크롬 버전, `getSettings()` 결과, 16 kHz 변환 방식, 페이지 주소, 확인 녹음 결과. 앞으로 모든 녹음은 이 설정을 따른다.
